Migración web

Cómo planificar una migración web sin perder SEO

Una migración web bien planificada protege URLs, contenido, medición y experiencia mientras la plataforma cambia de tecnología o estructura.

16 septiembre 2026 · Jonathan Díaz

Una migración es un cambio de sistema y de operación

Cambiar de CMS, rediseñar la arquitectura o consolidar dominios afecta mucho más que el código. También cambian rutas, contenido, enlaces, analítica y hábitos del equipo. Tratarlo como un simple traslado de archivos deja demasiadas decisiones críticas para el último momento.

Crea un inventario antes de construir

Registra las URLs actuales, su tráfico orgánico, enlaces entrantes, consultas principales, metadatos y función de negocio. Clasifica cada página: mantener, actualizar, combinar o retirar. Este inventario permite reconocer contenido valioso y evitar que una decisión visual elimine páginas que atraen visitas cualificadas.

Diseña un mapa de redirecciones

Cuando una URL cambia, define su destino equivalente con una redirección permanente. Evita mandar todas las rutas antiguas a la portada: el usuario y los buscadores necesitan una página que responda a la misma intención. Revisa cadenas, bucles, errores 404 y destinos irrelevantes antes de publicar.

Ensaya con una copia de pruebas

En un entorno no público, valida la estructura, el contenido, formularios, integraciones y datos estructurados. Comprueba títulos, canonical, robots, sitemap, imágenes y enlaces internos. Prueba también en móvil y mide rendimiento; resolver problemas antes de la salida reduce el costo de correcciones urgentes.

Coordina el día de lanzamiento

Alinea a desarrollo, contenido, marketing y operaciones. Define quién aprueba el cambio, cuándo se congela contenido, cómo se verifica DNS o caché y quién atenderá incidencias. Conserva una copia recuperable y acuerda criterios claros para detener o revertir la publicación si aparecen fallos graves.

Mide después de publicar

Los primeros días requieren seguimiento de errores, indexación, tráfico, conversiones, rendimiento y formularios. Compara con una línea base y revisa las páginas más importantes una por una. Una migración termina cuando la nueva plataforma funciona de forma estable y el equipo puede operar en ella.
