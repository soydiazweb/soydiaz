Qué es MCP (Model Context Protocol) y por qué le importa a tu empresa

MCP es un estándar abierto para conectar asistentes y agentes de IA con herramientas y datos. Qué resuelve, cómo funciona y qué revisar antes de usarlo en una empresa.

21 octubre 2026 · Jonathan Díaz

MCP (Model Context Protocol) es un estándar abierto para conectar asistentes y agentes de IA con las herramientas y los datos de una empresa. En lugar de programar una integración distinta para cada combinación de modelo y sistema, cada herramienta se expone una vez, con reglas claras, y cualquier asistente compatible puede usarla.

El problema que resuelve

Un agente de IA es útil cuando puede consultar el CRM, leer un documento o crear un borrador. Sin un estándar, cada conexión se construye a mano: una para el CRM, otra para el correo, otra para la base de datos, y todo se rehace si cambias de modelo o de proveedor. Eso encarece el proyecto y hace difícil controlar qué puede hacer la IA.

MCP propone una forma común de describir esas conexiones. Anthropic lo publicó como estándar abierto a finales de 2024 y desde entonces lo han adoptado otros proveedores y herramientas de IA, por eso aparece cada vez más en proyectos empresariales.

Cómo funciona, sin tecnicismos

  • El asistente (por ejemplo, un chat de IA o un agente) es quien recibe la tarea.
  • Los servidores MCP son conectores: cada uno expone un sistema de la empresa, como el CRM, una carpeta de documentos o una base de datos.
  • Cada conector ofrece tres cosas: herramientas (acciones, como “buscar cliente” o “crear borrador”), recursos (información que se puede leer) y plantillas de instrucciones.

El asistente ve qué herramientas hay disponibles, decide cuál usar y la ejecuta a través del conector, que aplica los permisos definidos.

Qué revisar antes de usarlo

  • Permisos mínimos: cada conector debe exponer solo lo necesario. Si el agente solo necesita leer, no le des permiso para borrar.
  • Procedencia: usa conectores oficiales o revisados. Un conector de origen desconocido puede leer o enviar información sensible.
  • Acciones con aprobación: pagos, envíos a clientes o cambios de datos deben pasar por una persona.
  • Registro: guarda qué herramienta se usó, con qué datos y con qué resultado.

¿Lo necesita tu empresa?

Si vas a usar IA solo para redactar o resumir, no. Si quieres que un asistente o un agente trabaje con tus sistemas, como el CRM, la tienda en línea, los documentos o WordPress, MCP es una buena forma de hacerlo ordenado y mantenible. Lo explico en el contexto de un proyecto completo en agentes y flujos de IA para empresas.
