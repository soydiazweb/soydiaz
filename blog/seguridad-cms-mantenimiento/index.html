Seguridad web

Seguridad en WordPress y Drupal: una rutina que sí se puede sostener

La seguridad de un CMS depende de actualizaciones, permisos, copias recuperables y responsables claros, no de instalar un plugin y olvidarse.

18 septiembre 2026 · Jonathan Díaz

La seguridad pertenece a la operación

WordPress y Drupal pueden sostener sitios seguros cuando se administran de forma responsable. El riesgo suele crecer por componentes abandonados, credenciales compartidas, servidores sin actualizar o copias que nunca se han probado. Ninguna plataforma elimina la necesidad de una rutina.

Mantén un inventario de componentes

Registra CMS, extensiones, módulos, temas, librerías, versiones y responsables. Elimina lo que no se usa y revisa la procedencia y mantenimiento de cada dependencia. Un inventario simple ayuda a identificar qué necesita revisión cuando se publica una actualización de seguridad.

Reduce accesos innecesarios

Asigna a cada persona el permiso mínimo que necesita para su trabajo y retira cuentas cuando cambia el equipo. Usa cuentas individuales, autenticación reforzada cuando esté disponible y un proceso controlado para compartir credenciales de servicios externos. Así se puede investigar una acción y limitar el impacto de un acceso comprometido.

Actualiza con una secuencia probada

Prioriza avisos de seguridad, revisa compatibilidad, prueba los cambios en un entorno de ensayo y conserva un mecanismo de recuperación. Aplicar actualizaciones sin comprobar integraciones puede interrumpir formularios o pagos; posponerlas indefinidamente deja problemas conocidos abiertos.

Verifica las copias de seguridad

Una copia solo resulta útil si contiene lo necesario y puede restaurarse en un tiempo aceptable. Define frecuencia, retención y almacenamiento separado del servidor principal. Programa restauraciones de prueba y documenta quién toma decisiones durante una incidencia.

Define responsables y registros

Establece quién recibe alertas, quién aprueba una actualización y cómo se comunica una interrupción. Revisa registros de acceso y errores con una frecuencia razonable. La seguridad mejora cuando las tareas tienen dueño, calendario y evidencia de que se completaron.
